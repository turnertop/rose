# Design references

These supplied, AI-generated concept images informed Rose's layout and pink
palette. They are design illustrations, not screenshots of a current release
or samples from an actual user library.

- [Original dark three-pane concept](../Dark%20Image%20Vault%20Gallery%20UI.png):
  folder navigation, image grid, and an inspector with annotations.
- [Pink glass concept](../Pink%20Liquid%20Glass%20Image%20Vault.png): soft pink
  surfaces, rounded panels, and accent colors.

The current applications have their own controls and platform behavior. The
macOS app defaults to static pink surfaces; optional live glass is available in
Settings. The Windows preview uses static surfaces and offers Pink, Dark rose,
and system appearance. See the root README and `desktop/README.md` for current
features and platform differences.

The original concept files retain their generation-provenance metadata.
